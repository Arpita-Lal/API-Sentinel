API-Sentinel: Runtime BOLA & Shadow API Detection Engine is an advanced API security platform that monitors API traffic in real time to detect unauthorized access and hidden API endpoints. Using eBPF, Rust, Python, and React, it identifies BOLA attacks, discovers Shadow APIs, and provides actionable security insights through an interactive dashboard.
🚀 Key Features
Real-Time API Monitoring – Captures and analyzes live API traffic with minimal system overhead using eBPF.
BOLA Detection – Detects unauthorized object-level access and prevents insecure direct object reference (IDOR) attacks.
Shadow API Discovery – Identifies undocumented, deprecated, or rogue APIs by comparing observed traffic with API specifications.
Behavioral Authorization Analysis – Detects abnormal user behavior and suspicious API access patterns.
Interactive Security Dashboard – Visualizes API inventory, security alerts, and threat analytics in real time.
OWASP API Security Coverage – Helps identify vulnerabilities based on the OWASP API Security Top 10 framework.
Automated Security Alerts – Generates instant notifications for suspicious API activities and potential attacks.
Comprehensive Reporting – Produces detailed security reports for monitoring and compliance purposes.
